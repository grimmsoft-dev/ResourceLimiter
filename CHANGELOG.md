# Changelog

## 1.0.1

- Installer: **Add engine folder...** button (and `Install.bat -Engine <folder>`) for engines the Epic Games Launcher doesn't list, such as moved, copied or source-built ones.

## 1.0.0

- First release: Level Editor toolbar toggle that caps the editor's CPU at 90, 70 or 50% and lowers its priority, memory priority, texture pool and frame rate to match. Prebuilt for UE 5.3.
